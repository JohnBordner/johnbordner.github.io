# Portfolio Site
Portfolio site built using React + Vite

## Getting Started

1) Clone gitrepo to folder

2) CD into folder and within the terminal run the following:

```
npm run i
```
3) start the development server

```
npm run start
```

4) When changes are made and you are ready to deploy

```
npm run deploy
```

Note: Domain must be reconfigured after deployment, should consider finding a fix for this.
